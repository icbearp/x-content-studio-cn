# 审阅与指标

## 发布前检查

`Pre-publication: fact check, source check, claim boundary, voice check, visual check, duplicate check.`

- Fact check：时效事实已在当前任务核验，数字、日期、主体和引用与来源一致。
- Source check：关键陈述能回到原始来源，链接和核验日期完整。
- Claim boundary：事实、推断、观点和未知边界清晰，没有伪造体验或结果。
- Voice check：语气符合作者真实表达，没有机械模板、虚假身份或强行互动。
- Visual check：每张最终 PNG 已打开检查，来源、中文、裁切和证据性质正确。
- Duplicate check：已检查近期草稿和发布记录；重复主题要么换角度，要么明确继续深挖。

## 状态与记录

`Status: draft / approved / published / retired.`

- `draft`：仍在编辑或待人工审核。
- `approved`：正文与媒体已获人工确认，但不代表已经发布。
- `published`：已确认在 X 发布；记录必须包含 X URL 和发布日期。
- `retired`：停止使用或不再继续迭代，保留原因。

不得仅凭本地文件存在或用户曾批准就标记为 `published`。已发布记录至少包含内容编号、标题或主题、最终正文版本、X URL、发布日期、状态和来源。

## 标签

`Tags: pillar, format, intent, evidence type, visual type, depth level.`

- `pillar`：金融、加密、科技、AI 工具、教程、经济或社会观察等栏目。
- `format`：完整单帖、教程、引用观点、分析、问题或审阅。
- `intent`：解释、教学、判断、讨论、记录或复盘。
- `evidence type`：官方来源、原始数据、原帖、媒体、实测或待验证。
- `visual type`：截图、数据图、时间轴、机制图、摄影、海报或概念图。
- `depth level`：快速说明、标准分析或深度拆解。

标签用于同类内容比较，不作为平台算法评分。

## 可得指标

`Metrics when available: impressions, dwell/expand, media engagements, bookmarks, replies, reposts, quotes, profile visits, follows, link clicks.`

只记录用户提供或平台可见的数据，并保留统计时间点、口径和截图或来源。`dwell/expand` 不可得时不要用其他互动量代替。不同内容比较时同时考虑发布时间、受众规模、媒体类型、主题热度和样本量。

Never infer missing metrics as zero. 缺失指标记为 `unknown` 或“未提供”，不能填 0，也不能据此计算比率或宣布规律。

## 复盘决策

`Decision: repeat structure / deepen topic / change entry point / retire topic / insufficient sample.`

- `repeat structure`：证据支持复用结构，但不要复制措辞。
- `deepen topic`：读者需求或数据支持继续补充机制、教程或案例。
- `change entry point`：主题仍有价值，但开头、受众问题或视觉入口需要改变。
- `retire topic`：证据不足、价值有限、风险不合适或多次验证后不值得继续。
- `insufficient sample`：样本量、观察窗口或关键指标不足，只记录假设，不宣布规律。

复盘记录应写明观察、可能解释、反例、样本限制和下一步验证。总互动数不能单独证明内容质量，也不能推导固定发布时间、发帖频率或平台权重。
